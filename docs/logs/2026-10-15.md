### S2 已完成（环境全部验证通过）

执行命令（原文）与结果：

```bash
conda create -n patchgrid python=3.9 -y                          # OK, Python 3.9.23
pip install <torch-1.10.1+cu111 wheel>                            # 2.1GB，4.5MB/s，OK
pip install <torchvision-0.11.2+cu111> <torchaudio-0.10.1+cu111>  # OK（但把 numpy 拉到 2.0.2）
pip install numpy==1.22.4 scipy==1.7.1 ... open3d==0.18.0        # numpy 钉回 1.22.4；igl==2.5.0 无 cp39 wheel，跳过（主链路不需要）
pip install tensorboard==2.7.0 protobuf==3.19.0                   # protobuf 冲突修复
conda install -c nvidia/label/cuda-11.8.0 cuda-toolkit            # nvcc 11.8（env 内）
conda install -c conda-forge gxx_linux-64=11 gcc_linux-64=11      # gcc 11（env 内）
cd patch-grid/metrics/lib/extensions/mesh2sdf_cuda
export CUDA_HOME=$CONDA_PREFIX ... TORCH_CUDA_ARCH_LIST=8.6 && python setup.py clean --all install  # 编译 OK
```

验证结果（命令输出）：
- torch 1.10.1+cu111：`cuda available: True, capability (8,9)`；4096² matmul（4.0s 含 JIT）+ autograd 通过；
- mesh2sdf kernel：单位球 SDF 球心 -0.4977、距面 0.7 处 +0.2（几何正确）；
- import 链：utils / trainer.trainer / dataset / torchgp.compute_sdf / open3d / skimage(lewiner) 全通过。

### 错误与修复链（每步均有根因，非盲目重试）

1. `TORCH_CUDA_ARCH_LIST=8.9` → torch 1.10 架构表最高 8.6 报错 → 改 8.6（sm_86 cubin 兼容 sm_89，实测验证）；
2. 编译缺 `cusparse.h` → 装 cuda-cudart-dev 不够 → 缺 `cusolverDn.h`（11.8 label 无独立包）→ 装 cuda-toolkit 元包解决；
3. tensorboard 2.7 + 新 protobuf → Descriptors 错误 → protobuf 钉 3.19.0（官方 yaml 同款）；
4. `igl==2.5.0` 无 cp39 linux wheel → 分析确认仅预处理死代码引用 → 不装（记 ENVIRONMENT.md）。
